# rbnetwork.my

News and analysis on SEO, AI search and web development, in English and Bahasa Melayu.

Live site: [rbnetwork.my](https://rbnetwork.my)

## About

rbnetwork publishes news, analysis, explainers and guides on how search is changing: traditional SEO, AI search (AEO and GEO) and web development. Each article is written in English and Bahasa Melayu.

## Built with

- [Astro](https://astro.build) with TypeScript
- Articles in Markdown, edited through [Sveltia CMS](https://github.com/sveltia/sveltia-cms)
- Hosted on [Vercel](https://vercel.com)
- Set in Instrument Sans

## Maintaining the site

Notes for the site owner, covering local setup, writing articles, settings and deployment, are in [docs/MAINTAINING.md](docs/MAINTAINING.md).
